# Продолжение работы с другого устройства

Актуально: 2026-10-09, версия исходников 0.3.2. Продукт называется **Zapret Manager**. Пользовательская команда остаётся `zapret-console`.

## Где находится проект

Источник истины: https://github.com/KrakeKrip/Zapret-discord-linux, ветка main. Путь на предыдущем компьютере был `/home/atlkhnv/Zapret-discord-linux`; на новом компьютере выберите любой каталог. Ветка, документы и код переносятся через Git. Установленный движок, root-owned venv, SSH-ключи, настройки и пользовательские профили не переносятся через репозиторий.

```bash
git clone https://github.com/KrakeKrip/Zapret-discord-linux.git
cd Zapret-discord-linux
git status --short
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[gui]' build
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software .venv/bin/python -m unittest discover -s tests -q
```

Без Qt: установите `-e .` и запускайте базовые проверки; GUI-тесты будут пропущены. Подробности в CONTRIBUTING.md. Для push настройте свой SSH-ключ или gh auth login на новом устройстве; чужой приватный ключ не копируйте в проект.

## Что реализовано

- Core: безопасное чтение conf.env, атомарные изменения, единая административная блокировка, сохранение/восстановление конфигурации и именованные профили.
- Client: read-only snapshot, SHA-256 revision и CAS, строгий JSON helper v1, sudo/pkexec, отсутствие автоматических повторов системных изменений.
- PySide6/QML: главная, профили, стратегии, диагностика, журнал; worker вне GUI-потока, подтверждения изменений, безопасное закрытие.
- Терминал: простое whiptail-меню. Textual удалён в TASK-007 по просьбе владельца. При отсутствующем движке 0.3.2 открывает экран недоступности вместо аварийного выхода.
- Установка: неизменяемые releases + current, root-owned GUI venv, launcher на системном Python для CLI/меню/root, rollback, два ярлыка, сохранение settings/state, DESTDIR.
- Миграция: подтверждённое владельцем удаление внешнего движка с root-only архивом и отдельное восстановление движка без старого стороннего меню. Восстановление поддерживает внутренние hard links списков, создаваемые самим адаптером.
- Публикация: tag v0.3.2 запускает release.yml; wheel, sdist, полный архив отслеживаемых исходников, SHA256SUMS, GitHub Release и GHCR package с файлами сборки.

## Состояние предыдущего компьютера — не переносить как предположение

Внешний backend был `/opt/zapret-discord-youtube-linux`, сервис `zapret_discord_youtube.service`, рабочая стратегия раньше `general_alt11.bat`, интерфейс enp9s0. Владелец сначала явно разрешил удалить движок, затем разрешил восстановить его. Последний показанный результат восстановления отказал на hard link; скрипт после этого исправлен. Успешное восстановление и доступность Discord после него не подтверждены агентом. Для текущего состояния используйте `zapret-console --doctor`, `--status` и read-only systemctl.

Архив прошлого компьютера: `/var/backups/zapret-console/legacy-20261009T175335Z.tar.gz`, журнал миграции рядом, каталог root-only. Архив отсутствует в Git и может не существовать на новом компьютере. Локальная установленная версия при последней проверке была 0.3.1, исходники — 0.3.2. Названия файлов desktop entry сохраняются для совместимости; работающий GNOME может показывать устаревшую подпись до нового сеанса. Не завершайте пользовательский сеанс автоматически.
