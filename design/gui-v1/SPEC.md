# GUI v1 — дизайн Codex

Эталон: main.svg, profiles.svg, strategies.svg, save-dialog.svg (1040×720). PNG — проверенные растровые копии; preview.html переключает экраны локально, без сетевых зависимостей и обращения к сервису. Все данные в макете — примеры. SVG предназначены для изучения, интерфейс реализуется живыми QML-компонентами.

Системный sans-serif; SVG отрисованы DejaVu Sans, но не нужно поставлять шрифт. Заголовок экрана 26 px/600, главный статус 27 px/600, заголовки карточек 17–18 px/600, основной текст 14 px, вторичный 12 px. Вспомогательные подписи 11 px, небольшие uppercase-метки 10 px. Никакого emoji или иконок из нестабильных Unicode-глифов. Линейные иконки 20–24 px, линия 1.8 px. Знак Z — простая локальная векторная фигура.

Sidebar 208 px, внутренние поля 16–24 px. Отступ контента от sidebar 32 px, справа 32 px. Заголовок начинается y=40, разделитель y=116, контент y=144. Карточки radius 14, кнопки 9, поля 9. Высота кнопки минимум 40 px, поля поиска 44 px. Бордер 1 px. Использовать реальные Layout/implicitHeight, а не абсолютные координаты SVG. У профилей минимум 10 px между нижней кнопкой и краем карточки.

Primary: мятная заливка, тёмный текст, только основное действие области. Secondary: графитовая заливка и бордер. Delete: спокойная secondary с красным текстом, destructive-заливка только в подтверждении. Disabled: приглушены заливка и текст, курсор обычный; недостаточно просто перекрасить работающую кнопку. Hover: осветление secondary на одну ступень, primary #8bebd0. Pressed primary #59cdae. Keyboard focus: явная контрастная рамка с отступом 2 px. Короткие переходы 100–140 мс, без бесконечного декоративного движения.

## Экраны

Главная: sidebar с брендом и тремя разделами, заголовок + «Обновить», большая карточка статуса с отдельным start/stop и restart, ниже текущая настройка (интерфейс, стратегия, переход в «Стратегии») и автозапуск (текстовый статус + явное enable/disable). Статус сервисной активности не является подтверждением доступности Discord: не писать «Защита включена», «Discord работает» или проценты успеха. Закрытие окна сохраняет работу сервиса.

Профили: счётчик с корректным склонением или нейтральным «Профилей: N», основная кнопка сохранения, прокручиваемые карточки с именем/стратегией/интерфейсом. Восстановить — справа; заменить и удалить — вторичные кнопки. Повреждённый профиль: текстовая отметка, warning-бордер, понятная причина, восстановление disabled, заменить/удалить доступны при пригодной revision. Не объявлять профиль текущим только по выбранной строке или совпадающему имени.

Стратегии: поиск, отдельная карточка фактической текущей стратегии независимо от фильтра, список доступных стратегий с кнопками применения и отметкой текущей. Если выбранная стратегия не установлена — отображать имя и предупреждение, не выдумывать новую текущую. Не модифицировать остальные параметры подключения. Текущая строка не отправляет повторное применение.

Общий footer: последнее событие слева, действительный статус сервиса справа. Цвет индикатора соответствует событию, не постоянно зелёный. Не придумывать время последней проверки или сетевой результат.

## Размеры и длинный текст

По умолчанию 1040×720, минимум 800×560. При ширине <960: нижние карточки главной ставить вертикально, контент прокручивается; заголовок/подпись переносятся, карточки профилей увеличиваются по высоте и переносят действия на следующую строку. Sidebar 184 px при узком окне, внешние поля контента 20 px. Dialog width min(456, window.width-48), высота по содержимому. Footer может усекать длинный lastEvent, полный текст доступен в tooltip. Имена/стратегии не должны растягивать окно: elide с tooltip либо перенос; ошибки всегда переносить. Список скроллится, фиксированные заголовок и footer остаются видимыми. При HiDPI использовать логические размеры Qt, не умножать вручную на devicePixelRatio.

## Состояния и сообщения

- Первое чтение: «Читаем состояние…», нейтральный индикатор; ни одной фиктивной настройки/активного сервиса. Идущий refresh не стирает предыдущий успешный снимок и не вызывает мерцания карточек.
- Остановлен: «Сервис остановлен», primary «Запустить», вторичная «Перезапустить» согласно действующему контракту. Неизвестно/ошибка: «Состояние неизвестно», нейтральный/warning стиль, без зелёной отметки; не менять старую логику доступности административных действий.
- busy/closing: индикатор и понятная подпись в footer, повторные изменения заблокированы; навигация и скролл работают. При closing — «Завершаем текущую операцию…»; не обещать отмену отправленной команды.
- revision=None/config error: встроенная warning-плашка с переносом причины; файловые действия выключены. Сервисные команды следуют существующему контракту.
- Профилей нет: центрированная небольшая иконка, «Пока нет профилей», «Сохраните текущую рабочую настройку, чтобы вернуться к ней позже»; ровно одна основная кнопка сохранения, без дублирования.
- Поиск без результатов: «Ничего не найдено», «Попробуйте другое имя стратегии»; текущая стратегия остаётся видна. Нет установленных стратегий: «Установленные стратегии не найдены», без обещания автоматической установки.
- conflict: «Настройки изменились в другом окне. Обновите данные и повторите действие.» Обновление не повторяет мутацию. Отмена системной авторизации — спокойное уведомление; operation_failed/transport_error — понятное сообщение, без сообщения об успехе при неизвестном результате.

Сохранение: модальный диалог по save-dialog.svg, фокус в поле имени, правила 1–48 ASCII: первая буква/цифра, далее буквы/цифры/_/-. Пустое/невалидное имя выключает primary до обращения к helper. Имя существует — сохранить действующий переход к явному подтверждению замены. Replace/delete: тот же визуальный стиль, имя цели в тексте; default/focus — безопасная «Отмена», для удаления — «Удалить профиль», для замены — «Заменить профиль». Ошибки и результаты стилизовать в едином компоненте. Escape отменяет диалог, Enter разрешён только для валидного enabled-действия. Все диалоги сохраняют revision, захваченную при открытии; poll не заменяет её.

Все тексты должны происходить из реального bridge/model. Не переносить home/mobile/backup/enp9s0/general_alt11 как тестовые данные в production. Макет не добавляет диагностику, журнал, настройки, автообновления, tray или новые backend-действия.
