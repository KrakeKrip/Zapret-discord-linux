# Сообщения об уязвимостях

Через GitHub Security Advisories репозитория можно сообщить о проблеме приватно, если владелец включил эту возможность. Не публикуйте приватные ключи, токены или действующие учётные данные в issues.

Интерфейс работает от обычного пользователя. Только системные операции вызываются через `sudo`. Приложение не добавляет правила `NOPASSWD`, не меняет настройки SSH и не скачивает код при запуске.

Административные действия сериализуются блокировкой. Конфигурация читается как данные, а не исполняется оболочкой. Значения проверяются до записи. Системные файлы настроек и код адаптера должны принадлежать root и быть защищены от записи обычными пользователями. Установленный launcher использует Python в изолированном режиме.

Приложение использует отдельный адаптер, который запускает сетевой движок и управляет firewall. Мастер установки загружает конкретный коммит адаптера с GitHub и запускает его загрузчик рекомендованного движка и стратегий. Коммит указан в `src/zapret_console/setup.py`; автоматического обновления адаптера при запуске меню нет.

Мастер не заменяет существующие каталоги и сервисы. Новый адаптер сначала загружается во временный каталог рядом с целевым. Ошибка загрузки удаляет только этот временный каталог; ошибка регистрации удаляет созданные мастером файлы. Проверка очереди и правил выполняется через отдельное административное действие `runtime`, которое не изменяет конфигурацию или firewall.
