## Перед передачей задания

Codex проверяет `git status`, учитывает существующие изменения и готовит самостоятельный TASK: контекст и конкретные файлы, цель, изменения, scope, ограничения, ожидаемое поведение, критерии приёмки, реальные команды самопроверки и формат отчёта.

GLM реализует только текущий TASK, не меняет ключевые документы без прямого указания, не делает commit/push и не меняет Git history. В отчёте указывает изменённые файлы, выполненные команды и результаты, необходимые сопутствующие изменения, непроверенные сценарии и ограничения. При архитектурном blocker возвращает вопрос Codex без самостоятельного расширения scope.

## Приёмка

После сообщения о завершении Codex начинает с `git status`, `git diff --stat`, `git diff` и проверяет новые файлы. Затем самостоятельно запускает релевантные проверки. Ошибки возвращаются GLM отдельным correction TASK с конкретными сценариями и ожидаемым результатом; несвязанные проблемы добавляются в очередь отдельно.

Принятый TASK оформляется одним атомарным commit после final review и необходимых обновлений документации. Push требует прямого указания пользователя. Пока GLM работает, Codex не изменяет рабочие файлы.
