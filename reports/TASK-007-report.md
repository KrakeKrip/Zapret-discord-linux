# TASK-007 — Zapret Manager и простое терминальное меню

Дата: 2026-10-09. Исполнитель: Codex. Версия исходников: 0.3.1.

Пользователь выбрал имя Zapret Manager и отказался от Textual из-за сложности терминального интерфейса.

## Изменения

- Название окна, sidebar, whiptail, CLI help, ярлыков и README: Zapret Manager. Команда zapret-console, имя Python-пакета и каталоги settings/state сохранены для совместимости.
- Textual удалён: исходники frontend, extra tui, установка зависимости и отдельный CI job. Его pilot-тесты заменены пятью тестами простого меню. Общие core/client, GUI и защиты от параллельных изменений сохранены.
- Запуск без параметров открывает прежнее простое whiptail-меню с действиями. --tui и --legacy-menu сохранены как скрытые совместимые варианты открытия того же меню. Противоречивые режимы отклоняются.
- Launcher использует venv только для --gui; меню не требует Textual, Qt или venv. Terminal desktop entry запускает меню без флагов. --ui tui оставлен как совместимое имя режима установки только меню, без Python-зависимостей.
- Установщик обновляет интерфейс даже при отсутствующем backend. Это необходимо после подтверждённого удаления стороннего движка; install.sh не создаёт его заново. setup.sh остаётся мастером установки движка и для такого обновления не нужен.
- Версия CLI теперь берётся из общего __version__, чтобы избежать расхождения с версией пакета.
