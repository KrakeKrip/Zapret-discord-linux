# TASK-005 — Textual и совместная работа интерфейсов

Исполнитель: Codex самостоятельно, по указанию пользователя. Зависимость: TASK-004B.

## Цель

Терминальное приложение с состоянием, явными start/stop/restart/автозапуском, именованными профилями, поиском стратегий, диагностикой и журналом. GUI/TUI используют общий клиент, один helper и общие lock/revision. Не вводить отдельный daemon или дублирующий путь записи.

## Критерии

- Запуск по умолчанию и --tui; прежнее меню --legacy-menu. Скриптовые режимы остаются без UI-зависимостей.
- Весь блокирующий ввод/вывод вне UI-потока, sudo получает обычный TTY через suspend, пароль не обрабатывается приложением.
- Формы фиксируют revision, конфликт не повторяется, недостоверный snapshot отключает файловые операции. Безопасная отмена и подтверждения замены/удаления.
- Закрытие ждёт операцию, не останавливая сервис. Работа без DISPLAY, 80×24.
- Пилотные проверки, реальный конфликт Qt/Textual и flock в временной установке, полный regression suite, wheel и CLI проверки.
- Системная установка, desktop-ярлык и живые привилегированные операции остаются TASK-006. Настоящий сервис и установленный пакет не изменяются.
