# TASK-006 — Системная установка GUI/TUI

Исполнитель: Codex, самостоятельно. Зависимость: TASK-005.

Установить полное приложение с root-owned изолированным окружением, GUI/TUI модулями и QML, двумя desktop-ярлыками и SVG-иконкой. Мастер Ubuntu/Debian устанавливает venv, polkit и библиотеки Qt. Поддержать all/tui/none, staging без загрузок и отдельную проверку реальных зависимостей в staging.

Перед активацией новой версии проверить импорты, launcher и данные. Не переносить готовый venv. При неудаче оставить предыдущую версию активной; защитить установку/удаление от ссылок и пересекающихся запусков. Сохранить settings, backend, systemd и профили; обновление интерфейса не должно менять сеть. Привилегированный helper использует системный изолированный Python без GUI/TUI зависимостей.

Проверить staging install/upgrade/uninstall, отказ при ошибках, безопасность путей и сохранение данных, GUI/TUI из установленного дерева, полный unittest и shell/CLI/dry-run. Реальная установка потребует sudo в пользовательском терминале: агент не принимает пароль. Push — только по отдельному указанию.
