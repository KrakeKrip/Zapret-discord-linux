# Changelog

## 0.2.0

- Мастер установки для Ubuntu/Debian: зависимости, зафиксированный адаптер, интерфейс, первый профиль и регистрация systemd-сервиса.
- Повторный запуск подключает существующую установку и сохраняет рабочие настройки.
- Режим `--dry-run` показывает план без загрузок и изменений.
- Диагностика различает состояние сервиса, процесс движка, правила firewall, обработчик очереди и сетевую доступность Discord.
- Счётчики пакетов сравниваются во время проверки; недоступные данные и маршрут через VPN не выдаются за успешный обход.

## 0.1.0

- Русское терминальное меню для управления существующей установкой zapret.
- Выбор стратегии с сохранением интерфейса и GameFilter.
- Сохранённый профиль, отмена изменения и возврат конфигурации при неудачном перезапуске.
- Проверка полной загрузки Discord, API и WebSocket с отображением маршрута.
- Управление systemd, журналы и настройка автозапуска.
- Проверка зависимостей, установщик, удаление, машиночитаемый статус и CI.
